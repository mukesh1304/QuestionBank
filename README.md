# 📚 CSVTU QuestBank

A centralized platform for accessing **Chhattisgarh Swami Vivekanand Technical University (CSVTU)** previous year question papers. Designed for B.Tech, BCA, MCA, and M.Tech students to make exam preparation easier and more organized.

---

## 🔗 Live Website

[🌐 Visit New Website](https://csvtu-questionbank.netlify.app/)

---

## 🛠️ Features

- 🏫 Course-wise access (B.Tech, BCA, MCA, M.Tech)
- 📁 Previous Year Question Paper collection
- 🔍 Easy navigation
- 🎨 Clean and responsive UI
- 📱 WhatsApp-based contribution & support

---

## 🧱 Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
- **Responsive Design**
- **PWA Support** (for app-like experience on mobile)

---

## 🚀 How to Use

1. Open the [website](https://csvtu-questionbank.netlify.app/)
2. Select your course (e.g., B.Tech)
3. Choose the semester and subject
4. View/download previous year papers
